### 架构变更

#### 新增：`/api/storage/presign` 路由
- 服务端用 service_key 生成 Supabase signed upload URL
- 客户端拿到 signed URL 后直接 PUT 到 Supabase（绕过 Vercel 4.5MB 限制）
- 生产环境已验证：presign → 200 OK，上传 → 200 OK

#### 重写：`files/page.tsx`
- 所有文件上传改用 presigned URL 流程（不再经过 Vercel）
- **50MB 大小限制**
- 音频文件保存完整的 `storagePath` + `url`（publicUrl）到 `minitu_files`
- 音频文件不再自动加入播放列表（由 MiniPlayer 手动选择导入）

#### 重写：`MiniPlayer.tsx`
- **导入音频文件 按钮**：点击展开导入面板，列出所有已上传的音频文件（从 `minitu_files` 读取）
  - 自动过滤已在播放列表中的文件
  - 复选框选择，支持全选/取消全选
  - 显示文件名 + 文件大小
  - "确认导入 (N)" 按钮批量添加到播放列表
- **上传新音频 按钮**：面板底部有"直接上传新音频文件 (最多50MB)"
  - 使用 presigned URL 流程
  - 上传后同时保存到 `minitu_files`（文件页也能看到）
  - 自动添加到播放列表
- 移除了旧的隐藏 `<input type="file">` 和 `handleFileUpload`

#### 简化：`MusicContext.tsx`
- 移除所有 console.log 调试代码
- 移除 URL 过滤/迁移逻辑（旧数据已清理）
- 保留云端同步功能（跨设备同步播放列表）
- 云端数据优先合并

### 用户操作流程（新）
1. 打开「文件」页面 → 上传 MP3 文件（最多50MB）→ 看到文件出现在列表中
2. 点击右下角音乐悬浮球 → 展开 → 点击"导入音频文件"
3. 看到刚上传的 MP3 出现在选择列表中 → 勾选 → 点击"确认导入"
4. 歌曲出现在播放列表中 → 点击播放
